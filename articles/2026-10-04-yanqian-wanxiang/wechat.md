<p style="margin:0 auto 12px;color:#18372F;font-size:24px;font-weight:700;line-height:1.5;text-align:center;letter-spacing:0.4px;">AI因注意力机制异常强大，而人类的注意力却涣散了</p>
<p style="margin:0 auto 8px;color:#68736A;font-size:14px;line-height:1.8;text-align:center;">AI 让造相的成本接近于零，人执迷的不再是某一个相，而是下一个新相。意落在哪里，哪里就构成一个人的现实——有限的一念，不该被无限的新相牵着走。</p>
<p style="margin:14px auto 24px;text-align:center;line-height:0;"><img src="https://lumisum.github.io/wulai/assets/wulai-wechat-divider.png" alt="" style="display:block;width:100%;max-width:100%;height:auto;margin:0 auto;"></p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">刷视频的时候，最容易被忽略的一件事，是我们正在怎样对待自己的心。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">一开始，可能只是想休息几分钟。看见一个有趣的，停下来；下一个更有趣，再看一会儿。等到终于放下手机，时间已经过去不少。可眼前那些原本要做的事情，并没有因此变得容易。有时反而更不想做了，还想再看一点。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">最近看见越来越多 AI 生成的视频，我更在意这个问题了。动物会说话，历史人物走进现代生活，不可能发生的事情，也能被做得像亲眼所见。画面越来越奇异，故事越来越出人意料，几乎总有一个新的场景等着我们。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">以前我把问题理解成：视频让人分心，所以要少刷，回到当下。这没有错，但只说到了一半。更准确的问题是：当相可以被无限造出来的时候，人的心会被牵到哪里去？</p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 执迷的不是相，是新相</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">过去说住相，容易理解成执着某一个具体的东西：看见美好的生活，执着那种生活；看见财富，执着财富。对象很明确，心抓着它不放。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">短视频时代出现了一种更特殊的状态：人甚至来不及执着于一个具体的相，他执着的是下一个相。上一条是会说话的动物，两秒就过去了；下一条是历史人物走进地铁，也过去了；再下一条是火星上的城市，还是过去了。我们并不珍惜其中任何一个画面，要的只是：再来一个我没见过的。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;"><strong style="color:#315B49;background-color:#EFF2EA;font-weight:700;padding:1px 3px;">所以真正让人停不下来的，不是某一条视频，而是新异本身。</strong>手指一直在换画面，心却始终停在同一个要求里：让我继续感到新鲜，别让我停下来。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">这件事在今天变得格外尖锐，是因为造相的成本变了。过去，现实世界制造一个新相很贵：要旅行，要拍摄，要演员、布景、特效和剪辑。一个惊人的画面，背后是许多人的时间和金钱。生成式 AI 把这件事的成本急剧压低以后，一个重要的变化出现了：相的供给，第一次远远超过了人的承受能力。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">人的一天仍然只有二十四小时，人的注意力依然有限。但相，已经接近无限。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">未来真正稀缺的，不是内容。是人的注意力。</p>
<p style="margin:26px 0;"><img src="https://lumisum.github.io/wulai/articles/2026-10-04-yanqian-wanxiang/images/01.png" alt="画面在换，心在追逐：手机上的想象景象不断翻新，观看的人仍被牵引。" style="display:block;width:100%;max-width:100%;height:auto;margin:0 auto;"></p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 意之所在，便是物</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">王阳明在《传习录》里说：「身之主宰便是心；心之所发便是意；意之本体便是知；意之所在便是物。」这句话放在这里，比任何关于专注的道理都更切题：你的意落在哪里，哪里就在构成你的世界。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">今晚有空出来的两个小时。意落在一本书上，这两个小时构成的是理解；落在孩子身上，构成的是你和孩子之间的一段关系；落在代码上，构成的是一个系统；落在音乐上，可能慢慢构成一首作品。物不是现成摆在那里的东西，意持续落下去，它才成形。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">可是如果意被切成二十秒一段、十五秒一段，在几十个、几百个毫无关系的对象之间高速跳跃，它就什么也构不成。画面看了很多，没有一样东西因为你的注视而生长。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">这也是我现在对刷视频最大的担忧。它最大的损失不只是浪费时间，而是让意无法长时间落在任何真正重要的物上。一门技术、一段关系、一篇文章、一个事业、一种修行，都不是看一眼就能长出来的，都需要人不断把意放在那里，时候久了，才慢慢成形。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">严格来说，一个人每天拥有的不只是二十四小时时间，而是每天一份有限的意。把它放在哪里，人生就在哪里生长。</p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 落意不是住相</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">讲到这里，有一个问题必须分辨清楚：佛家讲无住，阳明讲意要有所落——把意长久放在一件事上，不也是一种住吗？</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">区别在于意是不是由自己作主。住相，是意不由己：明明想停，停不下来；明明没有什么想看的，手指还在往下划。心是被相牵着走的。落意则相反：是我选择把意放在这里，认真地做，也能在该收的时候收回来。一个是被牵走，一个是自主地放。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">《金刚经》说：「凡所有相，皆是虚妄。」又说：「应无所住而生其心。」无住从来不是让人什么都不做、什么都不进入。佛陀在经里著衣持钵，出城乞食，回来吃饭，收衣钵，洗足，敷座而坐——每一件事都完整地做。事情普通，意却是整个地落在当下这件事上。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">我以前写过一位女同事开车的事。她平时很爱聊天，可车一上高速就明显安静下来，因为高速上最重要的事是把车开好。她的意整个落在驾驶上，不是不理人，是知道此刻该落在哪里。这样的专注里，没有追逐，也没有被牵走。</p>
<p style="margin:26px 0;"><img src="https://lumisum.github.io/wulai/articles/2026-10-04-yanqian-wanxiang/images/02.png" alt="此刻有此刻该做的事：女司机双手握住方向盘，专注于高速路前方。" style="display:block;width:100%;max-width:100%;height:auto;margin:0 auto;"></p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">所以两条线在这里接上了：佛家提醒人，不要把心交出去；阳明告诉人，心应该用到哪里去。内里不被万相牵走，外面仍然认真做事。可以看，可以知道，可以欣赏，但不必追。看过就过去，把意重新放回自己真正认定的事情上。</p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 注意力由谁支配</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">还有一层变化值得说清。2017 年，Transformer 的论文标题就叫《Attention Is All You Need》——注意力就是你所需要的一切。今天 AI 的惊人进步，根基之一正是这套注意力机制：让机器学会在海量信息里，判断什么值得注意。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">机器越来越会分配注意力，人却越来越不会了。当然，不是 Transformer 本身在抢人的注意力。真正完成这件事的，是生成模型无限造相、推荐算法筛选分发、产品机制持续争夺，三者合在一起。可结果摆在那里：</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;"><strong style="color:#315B49;background-color:#EFF2EA;font-weight:700;padding:1px 3px;">AI 用注意力创造智能，人却把自己的注意力交给了 AI。</strong></p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">所以最后的问题，不是你今天看了多少条视频。看十条、二十条，本身都算不上什么。真正的问题是：你的注意力，究竟由谁支配？是每一个新相出现，就自动被它领走；还是你清楚地知道，自己的意要落在哪里，并且守得住。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">自知的人不是不能看视频。区别只在于，看是他的选择，停也是他的选择；相再新、再奇，他的一念不跟着走。</p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 把一念留给真正认定的事</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">回到最开始的场景。下一次拿起手机，不必先责备自己，也不用立誓彻底戒掉。只需要多一个观察：当「再看一条」的念头起来时，先看看这颗心到底在等什么——是在等一个具体的、值得看的内容，还是只是在等下一个没见过的相？</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">如果是后者，就可以练习把手机放下，让意回到一件已经认定的事上。把饭吃完，把这段文字读懂，把家人的话听完，或者回到那件需要长时间投入、暂时还没有结果的事情里。意在那里多停留一会儿，那个「物」就多生长一分。</p>
