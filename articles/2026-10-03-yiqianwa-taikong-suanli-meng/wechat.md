<p style="margin:0 auto 12px;color:#18372F;font-size:24px;font-weight:700;line-height:1.5;text-align:center;letter-spacing:0.4px;">一千瓦的太空算力梦</p>
<p style="margin:0 auto 8px;color:#68736A;font-size:14px;line-height:1.8;text-align:center;">四颗芯片、一千瓦的电，第一颗算力卫星已经入轨；把事实放回本来的大小，才看得清这一步走了多远，离太空数据中心还有多远。</p>
<p style="margin:14px auto 24px;text-align:center;line-height:0;"><img src="https://lumisum.github.io/wulai/assets/wulai-wechat-divider.png" alt="" style="display:block;width:100%;max-width:100%;height:auto;margin:0 auto;"></p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 一千瓦的太空算力梦</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">四颗芯片，一千瓦的电，凭什么被讨论成“数据中心上天”？</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">消息传来，最先带走注意力的并不是卫星本身，而是“太空数据中心”这个名字。名字往往比实物先到，也最容易带着注意力先跑。冷静下来再看实物，反而踏实了一点：上天的不是一座数据中心，只是一次很小、也很诚实的测试。</p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 01 众缘和合，一星入轨</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">2026 年 10 月 1 日，代号 M1 的原型卫星由 Planet Labs 建造，搭 SpaceX 的 Transporter-18 拼单任务，从加州范登堡发射入轨，同批大约有 130 个载荷。谷歌已经确认和卫星取得了联系，运行符合预期，这一部分是确定的。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">卫星本身大约冰箱大小，里面装了 4 颗 Trillium 代的 TPU，靠太阳能提供约 1 千瓦的持续功率，差不多就是一台吹风机的量。在轨运行 Gemma 模型，回答一些简单问题，因为散热跟不上，每次只能跑约 15 分钟，整个任务期目标大约是一年。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">接下来几周，要收集的也都是最基础的数据：芯片扛不扛得住发射时的振动、太空里的辐射和极端温度。发射之前，已经做过三轴振动测试，芯片也在加州大学戴维斯分校接受过质子束照射，剂量约等于在太空待五年。准备做得再细，地面模拟也代替不了真的在轨道上待一阵子。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">细看这颗星的来路，颇有意思，并非任何一家单独做成的事。Planet 造星，SpaceX 负责发射，同批还有约 130 个载荷一起拼单，再加上地面提前做完的测试、刚好合适的轨道和日照，少了哪一样，2026 年 10 月 1 日都不会有这样一次入轨。所谓“谷歌的卫星”，说到底是一大串条件凑在一起才有的结果，没有哪一环能单独把功劳拿走。</p>
<p style="margin:26px 0;"><img src="https://lumisum.github.io/wulai/articles/2026-10-03-yiqianwa-taikong-suanli-meng/images/01.png" alt="少了哪一样，都不在那里" style="display:block;width:100%;max-width:100%;height:auto;margin:0 auto;"></p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 02 地有地的难，天有天的难</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">项目负责人的定性很克制：只是一次“非常小限度的测试”，先确认芯片能不能在太空里运行。相关说明同样明确：并非轨道数据中心，不对外提供服务，相关研究论文已经发表在《Joule》上。皮查伊发帖回忆第一次提出设想时的会议，也补了一句，还有很远的路要走。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">这份克制值得认真听。太空并没有把难题变没，只是换了一组难题。地面上建数据中心，卡的是电力、并网、用水和审批，几家巨头已经在签核电协议，想办法找稳定的电；到了太空，日照确实好得多，同样的太阳能板发电量最高可达地面的约 8 倍，账面看起来很美。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">可是另一面的账同样实在：太空是真空，没有空气对流，芯片的热只能靠辐射慢慢散出去，所以才只能跑 15 分钟就得停下来凉一凉。辐射会让芯片出错，发射成本更是横在最前面的一道门槛，业内估算要降到约 200 美元一公斤，整件事在经济上才可能成立，而那大概要等到 2030 年代中期。难题并不会因为换了地方就被消灭，条件一变，只是换一副面孔又出现，太空有方便，也有代价。条件还没有齐的时候，先用最便宜的方式把一个问题问清楚，想来正是这件事里最靠谱的部分。</p>
<p style="margin:26px 0;"><img src="https://lumisum.github.io/wulai/articles/2026-10-03-yiqianwa-taikong-suanli-meng/images/02.png" alt="难题换了一副面孔" style="display:block;width:100%;max-width:100%;height:auto;margin:0 auto;"></p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 03 钱种何处，心在何处</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">判断一家公司对一件事到底有多认真，先看钱花得有多重，比先听愿景讲得多大更可靠。这次的原型星花的是一笔小钱，买的更像一张入场券：万一十年后这条路真的走通了，至少不至于完全在门外。钱往哪里去，其实比话往哪里去诚实得多，投下去的是什么，日后长出来的才会是什么。谷歌真正的钱，仍然压在地面的数据中心和能源上，也没有给出任何星座建成的时间表。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">把口号和资金的流向放在一起看，真实的分量就出来了：现在种下的只是一颗很小的种子，说明现阶段只把这件事当作一个待验证的可能，是探索，还不是下注。区别并不难看，难的是，看新闻时目光往往只停在口号那一半。这颗星原计划是 2027 年初才发两颗原型，这次提前先送了一颗上去试水，节奏上也对得上“先问清楚，再决定要不要加码”。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">还有一个细节颇有意思：送卫星上天的 SpaceX，本身也有轨道算力的计划，承运方同时也是潜在的对手，发射仍然照常进行。商业世界里，合作和竞争原来可以是同一件事，不必非此即彼，这一点倒是比很多情绪化的解读更接近日常的真实。</p>
<p style="margin:26px 0;"><img src="https://lumisum.github.io/wulai/articles/2026-10-03-yiqianwa-taikong-suanli-meng/images/03.png" alt="看钱投向哪里" style="display:block;width:100%;max-width:100%;height:auto;margin:0 auto;"></p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 04 狂热嘲讽，皆是住相</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">回头看这条新闻传来时的第一反应，其实在两个极端之间晃了一下：先是冒出一句“这下真要搬上天了”，接着又冒出一点嘲讽，四颗芯片也值得这么热闹。晃完之后才看清，两种反应犯的是同一个毛病，都是把一个阶段当成了最终结果。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">只是一时之见，就像一开头带走注意力的那样，“太空数据中心”现在更像是一个先到的名字和画面，实体还只有四颗芯片和一千瓦的电。名字跑到了前面，不等于事情已经成了，也不等于就是一场骗局。不急着信，也不急着笑，把每一步放回本来的大小，这件事做起来不难，难的是对感兴趣的事情也这样做。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">技术一直在换地方，地面不够用，就想到太空，这条路本身没有错。只是顺带还有一问：跟着一起上路的，还有那只涨不降的算力需求，这一问，恐怕不在轨道上能找到答案。</p>
<p style="margin:34px 0 18px;padding-left:12px;border-left:3px solid #AB8966;color:#18372F;font-size:18px;font-weight:700;line-height:1.65;"><span style="color:#AB8966;font-size:12px;">◦</span> 05 事未成定，且观其变</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">所以这篇文章不给一个“看好”或者“看衰”的结论，时间还没到。接下来值得看的，是未来几周公布的在轨数据，芯片在真实辐射和温度循环里到底出了多少错，散热是不是和地面预估的一样。还有后面的激光链路测试和第二颗原型，因为一颗星只能单独运行，多颗星能不能连起来一起算，才是另一道完全不同的题。说到底，要看的都是后面的条件还会不会继续凑齐，缺了哪一样，后面的想象就还落不了地。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">再往远一点看，就是发射成本那条曲线，降得有多快，决定了前面的全部想象什么时候才需要被当真。在相关数据出来之前，先把这次入轨记成原本的样子：一个问题被认真地问了出来，答案还在路上。事情往后怎么变，今天定不下来，让事实慢慢显出样子，本身也是一种不急的看法。</p>
<p style="margin:0 0 20px;color:#354039;font-size:15px;line-height:1.95;letter-spacing:0.25px;">机器越送越远。被躲开的到底是什么，被追赶的又到底是什么？这个问题还没有答案，先留在这里。</p>
