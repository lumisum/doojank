<p id="wechat-title" style="margin:0 auto 12px;color:#24343B;font-size:24px;font-weight:700;line-height:1.5;text-align:left;letter-spacing:0.4px;">别逼苹果树结橘子</p>
<p style="margin:18px 0 26px;padding:14px 16px;background-color:#EFEADF;border-left:2px solid #996B34;color:#687478;font-size:14px;line-height:1.8;text-align:left;">目标要经常擦亮，行动要遵循现实条件。今天听《金刚经》第三品，我终于找到一条把发愿、行动与安心连进日常的路径：想要橘子，就种橘子树，别让强求牵着心走。</p>

<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">苹果树上结着苹果，一只手却把橘子举到了树前。想要橘子没有错，但苹果树不会因为你想要，就改了自己的规律。目标该怎样追，心又该怎样安住？今天有幸去一座寺庙，听了一位法师讲《金刚经》第三品，围绕“应云何住？云何降伏其心？”展开的讲座，让我对这两个问题有了很现实的理解。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">听完这次讲座，最大的一个收获就是，之前读《金刚经》或者其他佛经的时候，总感觉跟现实生活无法结合在一起。总觉得这些佛经讲得很有道理，但是如何在现实中真正应用呢？这是一个很严肃，也是很重要的问题。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">今天法师讲的时候，首先讲了“应云何住，云何降伏其心”。至于这两个问题是什么意思，其实说白了，就是一个问题：如果我们到了佛家所说的菩萨境界，发了阿耨多罗三藐三菩提心之后，也就是发了一个很大的心愿之后，我们的心应该如何安住？我们都知道答案，就是《金刚经》里所说的“应无所住而生其心”。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">然后法师又重点强调了一点，那就是“应云何住，云何降伏其心”有一个前提，就是你确实发了阿耨多罗三藐三菩提心，也就是发了一个大愿。这三个其实是合在一起的。如果你没有发这个大愿，其实也就不需要考虑如何安住、如何安心的问题。法师还说，这三个是一个类似于英语语法中“现在进行时”的概念，也就是一个持续的动作。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">我突然发现，这是一个对现实生活很有指导意义的解释。我们在现实生活中，其实不用考虑自己发了多大的心愿。你只需要想，我最近或者未来几年有一个目标，要实现某个计划。而这个目标，其实就相当于阿耨多罗三藐三菩提心。当然，这个目标应该是有一定难度的。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">当我们的目标确定之后，并不是说今天定了，明天、后天就不需要考虑了。而是要在我们核心的时间里，经常去刷新这个目标。所谓刷新，其实就相当于把这个目标或者大的心愿，在我们的心里、在我们的认知中，再次擦亮。一旦擦亮之后，它就会刺激我们，让我们牢记自己的阶段性目标或者使命。有了这个经常被擦亮的目标或者使命之后，它就会产生一定的督促和激励作用，推动我们采取行动。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">至于采取什么样的行动，我觉得是跟目标直接相关的。说白了，就是你的目标属于哪个领域，你就要使用那个领域相应的技能。会的话就去使用，不会的话就去学习和研究。这样一来，目标就推着我们往前走了。到这里，你有没有发现，我们其实已经获得了一种动力？这种动力促使我们不断刷新目标，研究策略、行动方案和具体步骤，思考如何一步一步实现目标，或者如何将目标拆解。这就是它很有现实意义的地方。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">那么，接下来所谓的“安心”又是什么呢？其实说白了，就是要遵从自然规律，遵从我们目标所在行业的客观规律。法师举了一个例子：“云在天边，水在瓶中。”这是很自然的一个现象。云随着气候和各种自然条件，在天边飘来飘去。而水在瓶中，你把它装进什么样的瓶子，它就呈现出什么样的形状。它不争，也不抱怨。这其实对我们奔向目标或者使命的过程，有着非常现实的指导作用。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">佛学里有一个经典思想，就是“缘起性空”。所谓缘起，就是各种条件共同组成了一个“一合相”；所谓性空，就是从本质上来讲，所有的事情都是无常的。这两个概念，其实就是在指导我们：在奔向目标的过程中，应该始终保持一种什么样的心态？</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">无论是小到某个具体行业，还是大到整个人生，我们都要看清并遵从其中的各种客观规律，不去强求。不强求是什么意思呢？举一个极端的例子，我不强求从苹果树上结出橘子，因为这是有悖于自然规律的。如果你想要橘子，那就应该种一棵橘子树。如果你种了一棵苹果树，就不要想着它能够结出橘子。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">这样一来，无论我们是在行业里打拼，还是在现实生活中，都可以避免很多由心而生的妄念，以及这些妄念对我们内心的牵动。而妄念牵动我们的心，恰恰就是人产生烦恼的一个重要原因。说到这里，你有没有发现，我们人生中几个核心的领域，无论是工作、家庭生活，还是兴趣爱好，其实都可以用这个道理来解释。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">所以，回到刚才所说的“现在进行时”。我们在自己的核心时间里，要让目标或者使命经常被刷新。同时，还要有一种觉悟，能够分辨自己在奔赴目标或者使命的过程中，每一步、每一个阶段、每一个小节点，是否产生了妄念。我们要能够分辨，这是妄念，还是自然本性。如果是妄念，就要避免让它牵动我们的心。一个比较直白的操作策略，就是把这个事情或者事物跟我们的心剥离开来，或者至少保持一定的距离。这样，就不会让我们的心被这些妄念牵着走。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">如果能够做到这个程度，我相信绝大多数人的生活都会变得更加积极乐观，心态也会更加稳定。而只要心态稳定了，整个人生其实也就稳定了。我觉得，这就是今天这场《金刚经》讲座给我带来的最大收获，也是佛法对现实生活最大的指导意义。</p>
<p style="margin:0 0 20px;color:#35464E;font-size:15px;line-height:1.95;letter-spacing:0.25px;">你觉得呢？</p>
