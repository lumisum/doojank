# 无来观世法

**总纲：道器一元，幽明一物。道是佛法思想，器是借鉴 Dan Koe 的文章构建思路。** 思想指导选题与判断，结构和文字让思想自然显现；两者在写作中共同形成，不先写通用文章再贴经文。完整含义与执行要求见 [文章构建方法总纲](../../../guides/writing-style.md)。

无来观世法以佛法作为核心底层思考向导：从因缘理解条件，从无常与空审视固定判断，从无住与我执反观心的抓取，以慈悲与智慧面对他人，回到日常实践。每篇选择切题的思想深入，贯穿问题、论证、结论与实践，不把经文作为事后装饰。

Dan Koe 的方法用于表达组织：具体困境 → 核心问题 → 原因解释 → 新的理解 → 可实践的改变。旧七层固定框架、去人称与强制佛法式小标题不再执行；佛法思想继续作为每篇的核心，不以效率或商业收益取代修行的意义。

## 使用方式

1. 阅读 [项目文章构建方法](../../../guides/writing-style.md)，它是统一方法来源。
2. 明确本篇佛法主线、读者正在面对的困境、作者核心判断，以及希望带来的认识或改变。用户要求分析时直接回答问题；要求文章时才构建成文。材料不足时完成有依据的部分，关键缺口再简洁询问。
3. 选择能解释问题的资料与例子。沿具体过程展开，辨明事实与判断；抽象处用读者熟悉的例子帮助理解。佛法用于观察欲望、执着、变化与生活实践，不能代替专业知识。
4. 检查作者原来的理解是否需要补充，提出有依据的新认识。允许“我”“你”等自然人称，不编造作者的经历，不虚构人物或组织的动机。
5. 按内容形成推进关系，让每节增加认识，最后回应困境，留下小行动或清楚的判断。没有个人行动可做的题材，不强凑步骤。

遇到题材选择困难时，参考 [不同题材的构建示例](references/domain-examples.md)。示例仅帮助构思，不是已核实的事实或固定模板。

## 写作与交付

- 标题、自然段、篇幅、语气与事实要求执行统一指南。新默认标题突出问题和阅读价值；用户明确要求章回对句时使用既有 5:5、7:7 或 8:8 格式。
- 调用 [文章写作技能](../wulai-article-writing/SKILL.md) 完成文章文件、摘要和交稿。中文审定后再处理英文，不自动发布讨论稿。
- 制作说明、配图构思和待查事项写在文章目录的 `production.md`，不混进 `article.md`。公众号与配图分别遵循 [排版指南](../../../guides/wechat-formatting.md) 和 [配图技能](../wulai-wechat-visuals/SKILL.md)。
- 借鉴结构与编辑方法，成文保留作者自己的观点与表达；不复制参考作者的句子、独有比喻或经历，不宣称本法能够解释世界万事或保证平台原创收益资格。
