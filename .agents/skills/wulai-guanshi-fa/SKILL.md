# 无来观世法

一套从问题出发、借专业知识理解条件与机制、并能随证据修正的分析与写作方法。目标是扩大可分析的问题范围，提高解释的具体程度；不宣称已能解释万事。经典提供观察角度，事实、论证与领域知识承担具体解释。文章可以不出现佛经词，但仍保留对条件、变化与执着的敏感。

## 思想底座

- 《金刚经》负责“拆”：不把暂时的结果、名字和身份误认成固定实体。
- 《六祖坛经》负责“照”：观察背后的欲望、恐惧、比较、身份、控制欲与意义需求。
- 《传习录》负责“行”：不听口头表态，看时间、金钱、行动和代价的实际去向；认知要经过行动才有资格叫“知”。

总纲：拆世界，照自己，入现实。

## 先明确要回答什么

先用一句话确定问题、对象、时间与尺度。背景不足时先完成可回答部分；关键歧义会改变结论时，再提出最少的必要问题。不要未经核对就接受问题的前提，例如“为什么成绩好的学生都很专注”要先确认“都”是否成立。

| 问题 | 需要交付什么 | 合适的依据 |
| --- | --- | --- |
| 是什么、发生了什么 | 定义、事实、范围与时间线 | 原始记录、测量、可靠出处 |
| 为什么、怎样发生 | 条件如何通过具体过程产生结果 | 机制、比较、实验或有依据的因果模型 |
| 将会怎样 | 有条件的预测、可能范围与变化信号 | 历史基准、模型、当前约束；不编造概率 |
| 应该怎样做 | 目标、备选行动、代价及取舍 | 因果判断加上明确的价值前提 |
| 意味着什么、是否值得 | 区分事实与赋予事实的意义，呈现相关立场 | 当事人表达、文本语境、伦理论证 |
| 是否必然成立 | 在明确前提下证明或找反例 | 定义、公理、逻辑推导；经验个案不能代替证明 |

一个问题可以含多个部分，分别作答。解释发生原因，不自动证明行为合理；预测结果，不自动决定应当选择什么；描述主观感受，也不自动证明外部原因。

## 按对象选择知识与方法

| 对象 | 优先查什么、怎样解释 | 人心与反观的位置 |
| --- | --- | --- |
| 自然现象、物理与生命过程 | 测量、领域理论、初始条件、物质与能量过程、尺度和适用范围 | 没有行动主体时跳过动机；反观只检查观察方法与模型局限 |
| 数学、逻辑与概念 | 定义是否一致、前提是否满足、推导是否有效、是否有反例 | 不用“执着”“因缘”替代证明；哲学联想另行标明 |
| 技术、工程与复杂系统 | 输入输出、组件依赖、瓶颈、故障证据、资源限制、反馈与延迟 | 有设计和使用者时再分析选择与激励，不给机器虚构意图 |
| 个人体验、学习与行为 | 当事人描述、能力、身心状态、任务条件、习惯、环境与时间变化 | 动机保留多种解释；单一行为不能推出人格或诊断 |
| 家庭、人际与组织 | 各方信息、权责、资源、规则、沟通、边界与相互反馈 | 区分善意、实际影响与控制需要；不因理解原因取消责任 |
| 商业、制度、社会与历史 | 一手材料、制度、利益、资源分配、历史路径、群体差异与偶然因素 | 组织不视为单一人格；历史重建与当下判断分开 |
| 意义、价值与终极问题 | 定义、价值前提、论证、经验表达与不同解释传统 | 可澄清问题与立场；暂无可判定依据时保留开放，不伪装成实证结论 |

跨领域问题逐段调用相关知识，并说明连接关系。例如“太空算力能否成立”涉及热管理、通信、发射成本与需求，任何一个角度都不能单独替全部条件作结论。专业知识不足时先查可靠来源；无法补足时缩小回答范围，指出具体缺口。

## 总原则

1. **按用户要求交付。** 讨论问题时给出直接、完整的解释；要求文章时交付可发布的成文。分析框架默认在后台运行，不把每次问答强制变成文章，也不自动创建文章、配图或发布任务。
2. **佛法的眼光落实到提问。** 因缘对应追查具体条件，无常对应观察变化与适用阶段，无住对应愿意修正判断。分析以问题为中心；成文时让这种观察贯穿相关章节，不为每章凑佛教词语，也不把自然现象都解释为人心问题。
3. **写文章时，章节小标题用带佛法感觉的句法命名**，双标签：一眼看出本章讲什么内容、一眼看出本章的观察眼光（如“众缘和合，一星入轨”“钱种何处，心在何处”“狂热嘲讽，皆是住相”）。标题要读者第一次看到就懂，不用晦涩典故。
4. **文章默认采用去人称、弱主体的文体；普通讨论以清楚自然为先。** 此处“破四相”是写作观察的借鉴，不把去掉代词等同于佛教修证，也不宣称这是四相的唯一解释。“全无主语”实际指不立叙述者人设，并非删除一切语法主语；用户明确要求其他文体时，以用户要求为准。
   - 叙述正文避免人称代词：我、你、他、她、它、我们、你们、他们、它们；事实引文、专名和经典术语保留原文，不为消除字面命中而篡改。
   - 叙述中避免笼统泛指人群：大家、人们、世人、人群、读者、所有人、这些人、那些人、别人、人家、人类；引文、专名与必要事实分类按语境保留，不把群体捏成统一意志。
   - 具体名称（公司、机构、物件、事件）可作事实主语，只作事实归属，不得写成拟人化的单一意志。
   - 体会与判断改用无主句：只写现象、条件和念头本身的起落；分寸用“只是一时之见”“就目前所见”“尚未”“大概”等词承担，不靠“我觉得”承担。
   - 破我相：不立洞见者人设，体会写明是体会；破人相：不立与“我”对峙的固定他者；破众生相：不把任何群体捏成单一主体；破寿者相：不写永恒延续的主体叙事，事情按条件与阶段写。
   - 成稿前扫描并逐处审视人称与泛指群体词，检查是否形成固定人设或群体意志；按词义和语境判断，不采用单字零命中的机械规则。
5. **判断可以保留，证据必须分层。** 事实、解释、判断、价值评价分开；证据足够时应明确判断，同时保留被后续事实推翻的可能。解释的质量看是否回答了原问题、说明了关键过程、与现有证据相容、明确成立条件，并指出仍未解决的部分；不要求所有问题都包含各方反应或知行冲突。

## 七层结构（后台运行）

先核事实，再形成解释；其余层次可往返修正。七层是可选视角，不要求每件事都凑齐。无行动主体时跳过人心、主体认知与行动层；形式问题优先证明，不强做事件因果分析。缺少证据的层次留白，不编造当事人经历、作者反应或私人信息。

1. **事实层**：核对时间、人物、地点、数字、原话、文件与发布顺序。分开事实／解释／判断／价值评价；标注信源等级，警惕拼接、旧闻新发与“为什么偏偏这个事件被看见”的筛选。事实不足时只写“目前能确认什么”，不补想象。
2. **结构层**：按领域拆解物质、能量、信息、资源、技术、制度与历史条件，追踪条件怎样相互作用，而非只列清单。有行动主体时，再看谁提供条件、谁承担成本、谁获得收益、谁有决定权、谁没有选择。把“个人问题”与“条件制造的结果”分开。
3. **人心层**：涉及行动主体时，从欲望、恐惧、比较、身份、控制、意义中选择有证据的角度。本层结论默认是假设；行动只能提供支持或反证，不能唯一证明动机。可保留有依据的推测，但明确限度，当事人动机不得写成已证实的事实。
4. **认知层**：分四级——认知（知道概念）、断知（能联系具体条件作判断）、行知（进入选择与代价）、验知（经结果检验并修正）。据具体材料观察理解、选择、实践与修正之间的落差；不凭片段给人物贴固定等级。
5. **行动层**：做“语言—行动对照表”：说了什么／做了什么／钱投向哪里／时间花在哪里／放弃了什么／承担了什么代价。不一致时调查能力、约束、信息与代价，不能只凭落差断定虚伪或特定动机。
6. **结果层**：分开预期结果、已发生的直接结果、副作用与二阶反馈链；结果不自动证明动机正确，也不把成功全归因于某个人或把失败全归因于某个人。
7. **反观层**：六问——为何偏偏此事触动己方？里面有无己方的欲望、恐惧、比较、身份或控制需要？若当事人是己方会如何做？己方的判断有无可能只是更精致的偏见？什么事实出现，愿意承认判断错了？此事是否暴露了长期问题？没有个人关联时，检查选题偏差、测量方式与解释前提即可，不虚构心路历程。

## 让解释经得起追问

1. **写清过程。** 按“在什么条件下，哪些因素通过什么过程，导致什么结果”组织解释。区分长期背景、必要条件、促成条件和直接触发因素；不要把“万物相联”“一切因缘”当作过程本身。不必罗列所有远因，优先保留会影响本次判断的因素。
2. **区分观察、改变与假设。** 同时出现不能直接推出因果。讨论“改变这个条件会怎样”要有实验、可靠机制或明确的因果假设；讨论“当初换一种选择会怎样”要交代反事实假设，不能把想象写成事实。检查共同原因、反向因果、筛选偏差与时间先后。
3. **比较有依据的替代解释。** 存在争议或证据不足时，至少考虑另一种合理解释，以及随机波动或测量问题是否足以说明现象。写出各解释得到的支持、冲突证据与区分办法；对已有充分证明或高度稳定的结论，不为凑数制造伪争议。
4. **说明能解释到哪里。** 能解释现象存在，未必能解释具体数值或时机；能说明平均趋势，未必能判断一个个体；事后说得通，未必能准确预测。承认解释的层次，不把各层混作一个结论。
5. **寻找可区分的证据。** 经验问题考虑什么新观察会增加或削弱某个解释；可行时建议成本合适的比较或小范围验证。历史问题依靠史料交叉核对，形式问题依靠证明与反例，价值问题检查前提、一致性与后果，不强套同一检验方式。
6. **检查变化与反馈。** 看短期和长期是否相反、局部收益是否转移了成本、行动是否改变了原来的环境。涉及复杂系统时考虑阈值、延迟、相互影响与偶然性，不默认投入增加就线性增益。
7. **允许部分解释并及时停下。** 明确“已有依据”“合理推测”“暂不能判断”及原因。不编造置信度百分比，不承诺好因必有预想的好果。达到当前问题所需的解释深度即可，不无限追溯到宇宙起源，也不为了完整故事填补未知。

细化示例见 [跨领域使用示例](references/domain-examples.md)。其中案例用于选择提问方式，不代表已完成事实调查或证明方法有效。

## 六个横向视角（按问题调用）

- **时间**：短期反应、长期结果、历史路径分开看，许多结论只是时间未到。
- **尺度**：个人、家庭、组织、城市、国家、文明尺度下结论可能完全不同。
- **利益**：不只看谁赚钱，还看谁获得注意力、身份、安全感、权力与道德位置。
- **激励**：观察制度奖励什么、参与者能否响应，以及约束和意外后果；激励能影响行为，不能单独决定一切结果。
- **反馈**：行为改变环境，环境再反过来改变行为，事件确有依据时写出反馈链；推演明确标为可能，不为满足形式编造。
- **边界**：每个结论注明适用对象、条件与不适用情形。

## 商业事件专用调整

拆商业、公司、市场类事件时，在七层之上再加五条：

1. **事实层硬化为数字层**：一手源优先（公告、财报、电话会纪要、招股书、监管文件），媒体只作转述。每个关键数字过三问：谁披露的（公司自述／审计／第三方，权重不同）、口径是什么（利润还是现金流、一次性还是经常性、标题数还是附注数）、和谁比（同比／环比／同行／市场预期）。数字打架先查来源与口径，不急着选一个。
2. **人心层降权并换对象**：公司不是人，禁止“这家公司慌了／贪了”式拟人化。人心只拆三块：决策者个人（任期、股权激励行权、对赌与 KPI）、组织惯性（区分主动决策与流程惯性）、市场参与者心理（怕什么、叙事是什么）。
3. **行动层等于资本配置**：钱投到哪、从哪撤，回购／分红／并购／资本开支，招人还是裁人，砍掉哪条业务线；必问“放弃了什么”。做“言语—资本配置对照表”，口号与资金流向对照着看。
4. **认知层加预期差**：动手前先写一行“市场此前预期了什么、已经定价了什么”；把实际与此前预期对照；“实际减预期”是分析提示，并非适用于所有事件的精确计算公式。无法确认定价时明确说明。
5. **结果层加对手反应**：竞争对手、客户、监管的下一步分别推演；区分领先指标（订单、库存、应收、招聘）与滞后指标（财报）。**反观层加持仓自检**：仅在作者提供真实持仓信息时声明；未知时不得替作者编造持仓或无持仓声明，自问换一个持仓状态会不会换一种说法。用本法分析投资时必须另加财务数据与风险分析，不以哲学代替专业研究，不输出买卖指令。

## 文章构建顺序

1. 先定问题与领域，再选择相关视角、专业知识与解释方式；审视替代解释后形成暂时判断，说明依据与成立条件。
2. 按事件需要登记验证指标、参考日期与证伪条件，作为制作笔记；不得据此自动创建回访、提醒或定时任务。后续有新证据时，可以修正已有判断。
3. 成文可从具体场景或清楚的问题进入，说明已有理解哪里不足，展开相关机制或论证，再落回判断与体会。只有事实支持时才写反常识、矛盾或反转；有明确答案就讲清，不为余韵故意悬置。尚待验证时，可自然带出“接下来值得看的是……”。
4. 每章先定眼光、再定佛法感小标题，然后写作；正文执行去人称规则，保持具体事实主语与来源归属。段落通常容纳两到四句话，避免一句一段；参照 [无来文章写作技能](../wulai-article-writing/SKILL.md) 保持平实易读，篇幅随用户要求与内容调整。
5. 公众号长文是源头；短视频（每条只取一刀）与小红书版本都是从长文改编的二级产物。

## 来源与发布文件

- 核对关键事实的一手来源，记录发布日期、链接、数字口径和核对日期。公司自述、实验数据、估计与设想分开写；未找到一手佐证时，不升级为确定事实。技术机制与成本预测尤其要核对前提，预测不写成已发生结果。
- 将必要出处自然放在相关段落或简短文末来源中，使用可辨认的超链接；不把内部分析表、置信度数值机械塞进正文。
- 正文保存在每篇文章目录的 `article.md`，配图、核对说明和待查事项放在同目录 `production.md`，并确保后者被网站构建排除。正文不得残留“配图安排”“发布信息”等制作说明，未生成的图片不得声称已完成。
- 公众号导出遵循 [排版指南](../../../guides/wechat-formatting.md)，实际配图遵循 [配图技能](../wulai-wechat-visuals/SKILL.md)。

## 最反对的七种写法（自检清单）

用结果倒推道德原因；用单一原因解释复杂事件；把人想得过于理性；把一切归结为“人性”；拿经典替代事实与证据；站在结果之后嘲笑当事人；把自己的分析当成真理。

## 交付前检查

- [ ] 事实层：关键事实有出处，事实／解释／判断／价值评价未混写
- [ ] 已明确问题类型与解释范围，调用合适的领域知识；没有把无关的人心分析硬套进来
- [ ] 解释包含具体过程或有效论证；有争议时比较了合理替代解释，且未混淆相关与因果
- [ ] 写文章时，小标题贴合内容与观察角度，正文没有硬塞框架
