# 无来观世法

一套把现实事件观照通透的分析与写作方法。经典是底层操作系统，现实语言是界面：文章里可以完全不出现佛经词，但观察方式始终在工作。

## 思想底座

- 《金刚经》负责“拆”：不把暂时的结果、名字和身份误认成固定实体。
- 《六祖坛经》负责“照”：观察背后的欲望、恐惧、比较、身份、控制欲与意义需求。
- 《传习录》负责“行”：不听口头表态，看时间、金钱、行动和代价的实际去向；认知要经过行动才有资格叫“知”。

总纲：拆世界，照自己，入现实。

## 总原则（定版，不可协商）

1. **最终产出是一篇完整的、可直接发布的公众号文章。** 分析、清单、七层结构都是内部过程，不出现在成品里；不交提纲、要点或半成品。
2. **佛法的眼光贯穿每一章。** 不能只在反观或结尾处露面，其余章节读起来像普通评论，即为不合格。每章写作时先定“这一章用哪只眼看”（因缘、条件迁移、知行、不住相、无常……），再落笔。
3. **章节小标题用带佛法感觉的句法命名**，双标签：一眼看出本章讲什么内容、一眼看出本章的观察眼光（如“众缘和合，一星入轨”“钱种何处，心在何处”“狂热嘲讽，皆是住相”）。标题要读者第一次看到就懂，不用晦涩典故。
4. **全文以破四相的方式构建（定版文体：全无主语）。**
   - 正文不出现人称代词：我、你、他、她、它、我们、你们、他们、它们，一律不用。
   - 不出现泛指人群词：大家、人们、世人、人群、读者、所有人、这些人、那些人、别人、人家、人类。
   - 具体名称（公司、机构、物件、事件）可作事实主语，只作事实归属，不得写成拟人化的单一意志。
   - 体会与判断改用无主句：只写现象、条件和念头本身的起落；分寸用“只是一时之见”“就目前所见”“尚未”“大概”等词承担，不靠“我觉得”承担。
   - 破我相：不立洞见者人设，体会写明是体会；破人相：不立与“我”对峙的固定他者；破众生相：不把任何群体捏成单一主体；破寿者相：不写永恒延续的主体叙事，事情按条件与阶段写。
   - 成稿前做一次全文扫描：禁用词零命中才可交付。
5. **判断可以保留，证据必须分层。** 事实、解释、判断、价值评价分开；证据足够时应明确判断，同时保留被后续事实推翻的可能。看透一件事的五条标准：能解释它为何发生、为何各方反应不同、为何知道却做不到、能指出改变哪个条件结果会变、能说清自己可能错在哪里。

## 七层结构（后台运行，顺序不可乱）

1. **事实层**：核对时间、人物、地点、数字、原话、文件与发布顺序。分开事实／解释／判断／价值评价；标注信源等级，警惕拼接、旧闻新发与“为什么偏偏这个事件被看见”的筛选。事实不足时只写“目前能确认什么”，不补想象。
2. **结构层**：拆六类条件——技术、经济、制度、激励、资源、历史路径；画出谁提供条件、谁承担成本、谁获得收益、谁有决定权、谁没有选择。把“个人问题”与“条件制造的结果”分开。
3. **人心层**：欲望、恐惧、比较、身份、控制、意义六项逐项对照事件细节找证据。本层结论默认是假设，须有行动层证据回证才能写成判断；当事人动机不得写成已证实的事实。
4. **认知层**：分四级——认知（知道概念）、断知（能联系具体条件作判断）、行知（进入选择与代价）、验知（经结果检验并修正）。指出当事人、公众、媒体与己方各自停在哪一级。
5. **行动层**：做“语言—行动对照表”：说了什么／做了什么／钱投向哪里／时间花在哪里／放弃了什么／承担了什么代价。不一致时以行动为准。
6. **结果层**：分开预期结果、已发生的直接结果、副作用与二阶反馈链；结果不自动证明动机正确，也不把成功全归因于某个人或把失败全归因于某个人。
7. **反观层**：六问——为何偏偏此事触动己方？里面有无己方的欲望、恐惧、比较、身份或控制需要？若当事人是己方会如何做？己方的判断有无可能只是更精致的偏见？什么事实出现，愿意承认判断错了？此事暴露了己方哪条长期问题？

## 六把横向刀（任何一层都可调用）

- **时间**：短期反应、长期结果、历史路径分开看，许多结论只是时间未到。
- **尺度**：个人、家庭、组织、城市、国家、文明尺度下结论可能完全不同。
- **利益**：不只看谁赚钱，还看谁获得注意力、身份、安全感、权力与道德位置。
- **激励**：制度长期奖励什么行为，就会批量生产什么结果。
- **反馈**：行为改变环境，环境再反过来改变行为，写出至少一条反馈链。
- **边界**：每个结论注明适用对象、条件与不适用情形。

## 商业事件专用调整

拆商业、公司、市场类事件时，在七层之上再加五条：

1. **事实层硬化为数字层**：一手源优先（公告、财报、电话会纪要、招股书、监管文件），媒体只作转述。每个关键数字过三问：谁披露的（公司自述／审计／第三方，权重不同）、口径是什么（利润还是现金流、一次性还是经常性、标题数还是附注数）、和谁比（同比／环比／同行／市场预期）。数字打架先查来源与口径，不急着选一个。
2. **人心层降权并换对象**：公司不是人，禁止“这家公司慌了／贪了”式拟人化。人心只拆三块：决策者个人（任期、股权激励行权、对赌与 KPI）、组织惯性（区分主动决策与流程惯性）、市场参与者心理（怕什么、叙事是什么）。
3. **行动层等于资本配置**：钱投到哪、从哪撤，回购／分红／并购／资本开支，招人还是裁人，砍掉哪条业务线；必问“放弃了什么”。做“言语—资本配置对照表”，口号与资金流向对照着看。
4. **认知层加预期差**：动手前先写一行“市场此前预期了什么、已经定价了什么”；事件的信息量等于实际减预期，不是事件本身。
5. **结果层加对手反应**：竞争对手、客户、监管的下一步分别推演；区分领先指标（订单、库存、应收、招聘）与滞后指标（财报）。**反观层加持仓自检**：先声明是否持有相关资产，自问换一个持仓状态会不会换一种说法。用本法分析投资时必须另加财务数据与风险分析，不以哲学代替专业研究，不输出买卖指令。

## 文章构建顺序

1. 后台跑完七层（含商业调整，如适用），得出暂时判断（注明置信度与成立条件）。
2. 登记验证指标：要观察的指标、观察日期、验证与证伪标准，日后必须回访；回访不怕改口，公开修正本身就是本法的一部分。
3. 成文结构：从一个反常识问题开头（不从概念、不从经典开头）→ 指出普通解释哪里不够 → 拆机制（条件、钱流、激励、对手）→ 找到真正的矛盾 → 中段反转回自身 → 结尾不强行给答案，留一个值得继续想的问题，并把验证指标化成“接下来值得看的是……”自然带出。
4. 每章先定眼光、再定佛法感小标题，然后写作；全文执行无主语规则。
5. 公众号长文是源头；短视频（每条只取一刀）与小红书版本都是从长文改编的二级产物。

## 最反对的七种写法（自检清单）

用结果倒推道德原因；用单一原因解释复杂事件；把人想得过于理性；把一切归结为“人性”；拿经典替代事实与证据；站在结果之后嘲笑当事人；把自己的分析当成真理。
