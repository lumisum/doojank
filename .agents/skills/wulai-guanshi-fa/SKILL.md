# 无来观世法 · 无来十段式

**七层求全，三反求真。事实先于理论，现实高于模型。后台充分分析，前台只留十个递进判断。**

本技能继续使用原调用名 `wulai-guanshi-fa`，写作方法更新为“无来十段式”。开始前读 [执行规范](../../../guides/writing-style.md)；需要核对作者完整要求时读 [V1.0 原始规范](../../../guides/wulai-ten-paragraph-v1.md)。原先不使用七层分析的限制由本次明确要求取代，Dan Koe 不再是必选组织框架。

## 分析与成文

1. 明确作者核心判断、真实素材、读者和任务阶段。分析请求就交付分析；成文请求才写正文，已有作者判断优先。
2. 考虑事实、认知、人性、利益、结构、演化、价值与行动七个角度。检验材料和机制，不编造动机、收益链、经历或必然趋势；缺失和不适用处保留边界。
3. 用立场反转、因果反转和结果反转检验原结论。寻找反例、共同原因、反馈与二阶效应；不能用修辞强造反常识或终局。
4. 选择一个核心判断，按执行规范将结果组织为十个自然段。正文不展示后台扫描过程、不编号、不介绍方法；公众号可加 3–5 个判断式导航标题。
5. 用 [文章写作技能](../wulai-article-writing/SKILL.md) 完成正文与交稿；中文默认 800–1500 字，复杂题材约 1800 字，英文每段默认 20–50 words。明确要求长文时优先执行作者要求。

佛法继续指导对条件、变化、偏见、欲望和行动的观察，其他学科辅助具体解释；正文默认不用佛学术语。科学和工程问题靠专业依据，不以哲学替代证明或测量。

资料默认在后台核对，关键依据、适用条件与编辑结论简洁记录于 `production.md`，不展开内部分析过程。正文保留事实、推论、预测和价值判断的区别；锋利不等于说死，指出限制后给出方向，不只揭露问题。

不同题材的材料取舍可参考 [构建示例](references/domain-examples.md)。这些示例用于准备分析，不替代十段式结构，也不作为已核实事实。

## 交付边界

摘要、平台语言、配图、文件和导出要求见文章写作技能。中文审定后才处理英文；方法更新不自动改写既有文章或发布。不得保证本法解释万事、平台流量或原创收益资格。
