# 无来原创研究辅助

保留原调用名，执行[原创内容方法论1.0](../../../guides/original-content-methodology.md)。**问题为始，思考为引，实践为证，价值为终。** 七层三反不再是必选框架，哲学只提供作者认可的视角，不保证解释万事。

## 工作方式

1. 确认作者请求的是选题、研究设计、核查还是审阅；仅提供该项辅助，口述润色转[口述技能](../wulai-article-writing/SKILL.md)。
2. 真实问题起步：谁关心，代价是什么，已有答案遗漏什么，作者有什么观察或探索条件。
3. 需要正式选题时填写[选题卡](../../../templates/original-topic-card.md)。未知字段留待定，核心结论可以空白。不要为了文章预期先确定答案。
4. 区分作者观察、公开依据、独立推论与猜想。优先复盘既有实践，再设计最小验证；写清条件、样本、时间、反例和失败，不把一次观察当普遍规律。
5. 按问题、研究、价值交付三个方面给出简洁审阅意见。证据缺口、建议和下一步行动放在正文之外，由作者决定。

研究设计不是实际执行；不自行测试、联系客户、花钱、开启监控或发布。六步表达链是审阅参考，不能据此自动重排或补写作者稿。结论可以未定，失败经验也有价值；不保证读者需求、流量或收益。

需要题材示例时参考[研究示例](references/domain-examples.md)，示例不是已核实结论。
