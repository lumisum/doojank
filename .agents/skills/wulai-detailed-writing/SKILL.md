# 无来长口述轻润色

执行[口述规范](../../../guides/writing-style.md)与[长稿规范](../../../guides/detailed-writing-style.md)。原“详解式”不再是代写格式。

读完全文后只修措辞、明确口误、标点与口述重复。保留所有实质判断、案例、论证步骤、顺序、限定词与结尾；不为连贯补因果，不为深度加概念，不为篇幅增删观点。

没有3000–6000字或其他最低字数。没有固定段数、章节或六段模板。长稿不是扩大助手编辑权限的理由。

作者请求排版时可调整自然段与适度强调，不重排思考或新增小标题，除非本次另有要求。疑点单列给作者，不擅自改为自己的判断。

文件、翻译与平台交稿见[口述技能](../wulai-article-writing/SKILL.md#平台与文件)。保存、翻译和发布按当次请求处理，不能因为长稿整理自动生成英文、配图或上线。
