# 无来文章写作

执行项目总纲：**道器一元，幽明一物。道为佛法思想，器为借鉴 Dan Koe 的文章构建思路。** 从构思起就让佛法主线进入结构与表达，通读时检查思想与文字是否一致。

## 开始前

阅读 [文章构建方法](../../../guides/writing-style.md) 与 [公众号排版规范](../../../guides/wechat-formatting.md)。采用项目统一的新方法，不恢复七层分析、去人称或强制佛法式小标题。需要构思或分析问题时可调用 [无来观世法](../wulai-guanshi-fa/SKILL.md)。

阅读用户原稿与真实背景，明确本次是分析、润色、重构还是成文。用户修订稿及指定核心判断优先；不补造经历或擅自改变作者立场。

## 构建文章

- 先明确本篇的佛法主线，以因缘、无常、空、无住、我执、慈悲或智慧中切题的思想指导提问、核心判断与实践。佛法贯穿全文，不只作结尾引用；不强凑术语，不将修行简化为效率、成绩或收益。

- 明确具体读者、困境、核心判断和读后变化，用具体问题或经历尽快建立阅读理由。
- 解释原因与过程，让各章节逐步深入；抽象概念用贴切例子说明。佛法体会落到具体生活，资料与推测保留来源和条件。
- 用“我”保留作者观察，用“你”适度连接读者；自然段通常 2–4 句，少量短句用于转折。不要逐句换段或机械拼接原有短句。
- 标题默认清楚的问题、判断或阅读价值，不强制章回对句。标题待定时交付三个高候选并推荐一个；用户指定章回形式时严格执行 5:5、7:7 或 8:8，同次候选用同一格式。用户已有指定标题则保留。
- 结尾回应开头，给出可实践的小行动、观察问题或清楚判断，不强凑清单或承诺效果。
- 常规篇幅参考 1500–2000 汉字，用户指定长度优先；长文围绕单一主线分章，避免重复和离题。
- 借鉴参考作者的编辑思路，使用无来的独立表达；不复制他人的特征性句子、比喻和经历。

## 平台语言

公众号使用中文文章、中文标题和中文图片；X 与英文 Pages 使用全英文文章和英文封面，正文纯文字，不生成或插入内部配图；中文版继续配正文图。中文确定后再构建英文，英文封面以正式英文标题直接生成，不能借用中文图并只翻译图注。执行 [平台语言规则](../../../guides/english-edition.md)。

## 文件与交稿

1. 按 [文章模板](../../../templates/article-template.md) 维护 `articles/<日期-短名>/article.md`，配图在同目录 `images/`。策划、待查资料与配图安排只放同目录 `production.md`，正文不带制作说明。
2. 通读正文，检查佛法是否实质指导判断与实践，以及开头阅读理由、论证推进、事实限度、自然段与结尾用途；新增判断明确交由作者审定。
3. 中文确定后，再按 [英文指南](../../../guides/english-edition.md) 构建对应英文；发布或实质更新时同步维护，中文讨论阶段不提前生成英文或替换线上稿。
4. 定稿并需要公众号导出时，运行 `python3 scripts/export_wechat.py` 生成公众号 HTML 与 Markdown。执行已有 15px、顶部封面与青松绿排版，不因方法更换改变视觉要求。
5. 需要 X 交稿时，以英文 Pages 定稿为唯一正文来源，运行 `python3 scripts/export_x.py <文章目录名>` 生成 `x.html` 富文本复制页与 `x.md` 备用稿。标题单独复制，英文封面 `5:2` 单独上传，正文纯文字；不能承诺 X 保留网页字号、颜色或所有粘贴样式。详见 [X 排版交稿](../../../guides/x-formatting.md)。
6. 有配图请求时按 [配图技能](../wulai-wechat-visuals/SKILL.md) 制作，不为画面文案改写核心观点。发布行为按用户当前授权执行，不由技能扩大权限。
