# 无来成文接收与视觉交稿

## 当前分工：作者成文，助手制图

2026-10-12起，作者直接提供成文。默认只构思并制作封面与正文配图，不润色、不重写、不改标题、第一段、顺序、观点或结尾。研究方法与How to主线用于理解作者内容，不授权补写。只有作者之后明确提出新的文字编辑任务时，才处理其指定范围。

每套封面与正文配图同时交付中文、英文版本。此要求针对视觉素材，不自动授权翻译或改写文章全文。图中文字忠实提取或概括成文中的已表达内容，英文准确传意，不新增结论。

## 执行

1. 通读成文，识别真实问题、How to主线、核心判断、机制、证据与行动落点，不修改文字。
2. 用[配图技能](../wulai-wechat-visuals/SKILL.md)构思信息密度高、形象化的封面及正文图，同时准备中英文视觉版本。
3. 给出每张图对应的原文位置、信息作用及短文案。缺少数据或含义不明时询问或单独提醒，不替作者补事实。
4. 文件、排版与发布按当前任务处理，成文原件保留；默认不自行插入图片改写article.md，不自动创建英文全文、推送或上线。已获明确授权的工作继续完成。

旧稿仍处于归档下架状态。此前口述轻润色技能只适用于作者明确要求润色的任务，不能在收到成文时自动应用。研究方法见[原创内容方法论](../../../guides/original-content-methodology.md)，文字编辑边界见[规范](../../../guides/writing-style.md)。
