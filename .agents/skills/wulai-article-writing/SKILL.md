# 无来文章写作 · 十段式与详解式

执行 [项目写作规范](../../../guides/writing-style.md)。十段式原始要求见 [V1.0](../../../guides/wulai-ten-paragraph-v1.md)。需要分析时用 [无来观世法](../wulai-guanshi-fa/SKILL.md)。两种写法共用事实、风格与交稿规则，正文结构分别执行。

## 先选写法

- 作者指定十段式：十个递进自然段，集中表达判断。
- 作者指定详解式、完整展开、一脉相承或不分章节：使用 [无来详解式技能](../wulai-detailed-writing/SKILL.md) 与其规范，不限定段数，不分章节，不用十段规则压缩。
- 未指定时按材料选择：能用短篇讲明的集中判断用十段式；需要较长因果链、概念区别、案例与边界才能讲清的问题用详解式。在制作笔记记录选择，不在正文介绍写法。平台不决定文章必须长或短。

## 写作

- 先读作者原稿、核心判断和事实背景，明确是分析、改稿还是定稿；不编造经历，不擅自替换作者立场。
- 后台检查七个角度与三重反转，不硬凑不适用的角度。十段式正文围绕一个核心判断呈现十个自然段，每段通常2–4句，判断后给必要理由或例子。
- 十段式逐段作用：核心判断→拆常见理解→人性→利益→结构→时间推演→阶段抬升→立场或定义反转→因果反转→结果反转及方向。正文不编号、不显示后台框架、不把十段变成十句断言。详解式依理解所需的顺序连续展开，不套这个固定段落顺序。
- 十段式中文默认800–1500字，复杂题材约1800字，公众号可加3–5个判断式小标题；这些不是详解式的字数或章节规则。详解式自然分段，无小标题与正文列表，中文正文默认3000–6000汉字，在范围内按讲清问题的需要决定篇幅。
- 十段式英文十段，每段默认20–50 words；详解式英文保留完整论证，不限定段数或短段字数。两者都用自然、专业、直接的英语重新组织同一意思，不逐字硬译、不另加判断；X正文不加章节导航、不一句一行。
- 判断先于解释，少形容词，多因果与具体关系；有证据时直接说，真正不确定处保留条件。反转必须成立，不读心、不造阴谋、不以虚假二选一营造锋利。
- 佛法是底层思维，正文默认使用日常语言。非明确要求或不可替代的题材需要，不主动提读经、佛学术语或用经文收尾。
- 资料后台核对，默认不在正文复述报告或加超链接。快速变化题材优先最近一年一手资料；特定事实、数据或独有发现必须准确归属，不把他人发现包装成原创。
- 标题制造贴题的认知冲突；待定时给三个高候选并推荐，指定标题保留。要求章回形式时核对 5:5、7:7 或 8:8。
- 中文导读 ≤100 字，英文 caption ≤256 个字符，包含空格与标点；写入 `summary`，不计正文十段。

## 平台与文件

1. 维护 `articles/<日期-短名>/article.md`；[模板](../../../templates/article-template.md) 的十段骨架仅用于十段式，详解式只借其元数据和文件约定。计划、来源、写法和配图说明放 `production.md`，记录 `writing_mode: ten-paragraph` 或 `writing_mode: detailed`。后台记录关键事实和编辑结论，不输出完整内部思考过程。
2. 通读单一主线、段间递进、必要因果、事实边界和现实意义；十段式另核对十段结构，详解式另核对完整解释与自然衔接。删重复与无关背景，不删到只剩口号，不营造智识优越感或无助感。
3. 中文审定后按 [英文指南](../../../guides/english-edition.md) 创建对应英文 Pages；英文 Pages 与 X 共用定稿。讨论稿不自动翻译或上线。
4. 需要公众号交稿时按 [排版规范](../../../guides/wechat-formatting.md) 运行 `python3 scripts/export_wechat.py`，生成 `wechat.html` 与 `wechat.md`，保留 15px、顶部中文封面与复制 caption 工具。
5. 需要 X 交稿时运行 `python3 scripts/export_x.py <文章目录名>`，生成 `x.html` 与 `x.md`；标题、英文封面和 caption 单独复制或上传。需要单帖或 Thread 时按 [X 指南](../../../guides/x-formatting.md) 另准备发布稿，不保证粘贴保留全部样式。
6. 图片使用 [配图技能](../wulai-wechat-visuals/SKILL.md)：默认中英文正文均不配图，只制作无字封面，以新奇图形关系表达主旨；中文公众号封面 2.35:1，英文 X/Pages 封面 5:2。配色依文章主旨；正文图与带字图仅按当前明确要求制作。

方法更新不自动授权批量改稿、制图、发布或推送；发布依当前任务要求执行。
