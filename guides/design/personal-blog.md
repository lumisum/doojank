# 无来个人博客：折叠空间

无来 / Wulai，双语个人博客，记录技术、工作、家庭、成长与自我的观察。文章按时间呈现，不分组。

## 当前视觉与布局

- 深空蓝 #09111f、冰蓝 #62d9ff、银白 #e6edf9、少量紫色 #a793ff。无衬线字体，深色玻璃、细边缘高光、多层阴影营造科技感。
- 新无字首页图片：烟色玻璃与钛金属折成不可能的环带，内侧展开海面，表现通过不同视角看见现实。
- 顺序：主视觉 → 四部经典图片 → 三列文章展览 → 个人介绍与二维码 → 轻量访问统计。
- 经典在桌面一行四部，保留现有图片；平板与手机两列。文章桌面一行三篇，平板两列、小屏一列；最新文章也使用同尺寸卡片，不跨行。
- 卡片有边缘光、浮起阴影、轻微的鼠标跟随倾斜，避免夸张旋转。触屏与减少动态用户不启用倾斜；正文阅读区保持稳定。
- 标题完整显示在封面下方，导读精简；搜索与语言切换继续保留。二维码维持白底扫码清晰度。
- 文章页同步深蓝科技配色，正文使用柔和银白、固定阅读宽度、清楚的链接和重点。
