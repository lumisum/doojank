# 无来个人博客：冷白与折叠空间

无来 / Wulai，双语个人博客，记录技术、工作、家庭、成长与自我的观察。文章按时间呈现，不分组。

## 当前视觉与布局

- 默认亮色：冷白 #f5f5f7、纯白 #ffffff、深墨 #1d1d1f、蓝色 #0066cc。参考苹果官网的留白、简洁导航、清晰标题与大图布局；保留无来自己的主视觉、品牌与内容。
- 暗色保留原版深空蓝 #09111f、冰蓝 #62d9ff、银白 #e6edf9、少量紫色 #a793ff。导航的月亮/太阳按钮切换明暗，浏览器记住选择，跨中英文页面共享；未选择时默认亮色，不随系统自动变暗。苹果亮色版使用新的主题偏好键，旧版暗色记录不再覆盖新默认值。
- 亮色使用白色卡片、柔和蓝灰阴影、圆角与细边框营造轻微立体感。人物温度来自真实个人介绍、二维码交流入口、自然语句和少量暖灰，不依赖密集霓虹或装饰。
- 新无字首页图片：烟色玻璃与钛金属折成不可能的环带，内侧展开海面，表现通过不同视角看见现实。
- 顺序：主视觉 → 四部经典图片 → 三列文章展览 → 个人介绍与二维码 → 轻量访问统计。
- 经典在桌面一行四部，保留现有图片；平板与手机两列。文章桌面一行三篇，平板两列、小屏一列；最新文章也使用同尺寸卡片，不跨行。
- 卡片有边缘光、浮起阴影、轻微的鼠标跟随倾斜，避免夸张旋转。触屏与减少动态用户不启用倾斜；正文阅读区保持稳定。
- 标题完整显示在封面下方，导读精简；搜索与语言切换继续保留。二维码维持白底扫码清晰度。
- 亮色首页顶部为冷白背景、居中深色标题和蓝色按钮；原 Banner 保留在介绍区下方，作为独立的圆角图片。暗色首页继续使用原来的背景图叠字布局。
- 文章页随主题切换：亮色为纯白阅读面、深灰正文和蓝色链接，暗色为深蓝与柔和银白。两种版本都使用固定阅读宽度和清楚的重点。

## 实现

`assets/css/blog.css` 保留暗色原版；`assets/css/blog-light.css` 仅在根元素的 `data-blog-theme="light"` 状态下覆盖配色与表面样式。页头在样式加载前恢复已保存的主题，减少闪烁；`assets/js/blog.js` 负责按钮标签、主题切换与同源标签页同步。禁用脚本时默认亮色，隐藏不可用的切换按钮。复制用的公众号/X 导出文件独立于 Pages 的主题偏好。

## 经典边界

`/classics/` 和 `/en/classics/` 继续使用原主题、字体、配色、阅读模式与音乐。blog.css 和个人博客交互只加载到经典以外页面，不改变经典资料及阅读脚本。
