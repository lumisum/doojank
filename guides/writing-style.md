# 无来文章写作风格

无来的文章从自己的生活经验和阶段性体会出发，平实、真诚、有思考。佛法是观察生活的一面镜子，不把个人感悟写成对读者的训诫，也不把尚在学习中的理解包装成权威结论。整体追求大道至简：观点说清楚，例子落到生活，不靠堆砌术语、口号或华丽句子制造深度。

## 叙述方式

- 从真实、具体的经历或一个确切的问题开始，再由经历自然引出佛法观察，最后落回普通人的生活。不要先摆一套抽象道理，再硬找故事证明。
- 保留作者的第一人称、观察角度和语气。润色是让意思更清楚、更顺，不替作者编造细节、动机、情绪或结论。
- 佛法概念用日常语言解释，并给出具体情境。区分经文原意、传统解释和作者个人体会；不夸大一次体验能够证明的内容。
- 句子长短可以变化，但避免连续堆叠“这让我想到”“所以我越来越觉得”“真正……”“这其实……”等相同起句，也避免把每个观点都改写成口号。
- 少用训诫、居高临下的断言和刻意煽情。结尾回到文章最初的问题或一个朴素可行的提醒即可。

## 段落节奏

- **正文以自然成段为默认。**每段围绕一个完整意思，通常由 2–4 句组成；相邻句子属于同一层意思时放在同一段，不要一句话就空一行。
- 段落应按叙事、论证或视角变化划分，不按每句话划分。连续的短句若共同完成一个意思，就合并成一段；列表或确需逐项强调的内容除外。
- 一句话独立成段只用于少数有意设计的转折、停顿或核心句。1500–2000 字的文章通常控制在 3–6 处，且不应让独立短句段落成为全文主体。
- 避免把正文写成诗行或演讲提词稿：例如连续出现“事情已经完成。”“但我不放心。”“后来我明白了。”并各自独立成段。应将意思连贯的句子组织成完整段落。
- Markdown 中空一行代表新段落，也会在公众号导出稿中形成新的段后间距。不要为了制造视觉留白，在每个句号后都插入空行。

## 标题

标题要简短、准确、有点击欲，优先从文章真实经历与核心体会之间提炼张力。无来标题可含蓄、有诗意和佛意，但用自然中文，不写夸大的因果承诺、绝对化判断或商业化热词。章回式对句可采用 5:5、7:7 或 8:8，即两句分别为 5、7 或 8 个汉字；根据每篇文章选择最合适的长度。两句应句式协调、尽量对仗，词义相承或相映；可前句落在真实人事物，后句转出文章体会或佛意。读者必须能轻松看懂标题字面和两句关系，不能为诗意、佛意或对仗牺牲清楚自然。构思后按贴题、作者立场、易懂、对仗、诗意佛意和点击吸引力审视，最终只交付三个同一格式的高候选，并指出最推荐的一项；逐字核实字数与用词自然度。

## 篇幅与交稿

- 公众号文章通常以 1500–2000 个汉字为参考，优先保证经历、思考和结论完整；不为凑字数重复观点，也不为追求短而删掉必要的推理。
- 用户提供完整修订稿时，以用户文本为准；除非用户要求重写，不擅自改变主旨、个人语气或事实。需要时只调整错字、表达和段落组织。
- 用户明确提供长文时，采用长文方式整理，不套用 1500–2000 字的常规篇幅。保留完整问题链、论据和思想实验，按主题设章，正文仍以自然段为主；段落合并后继续润色衔接，不能只把短句机械拼在一起。事实、研究与未来假设分清，必要的澄清融入论述。
- 长文可在 Front Matter 设置 `longform: true`，网站会提供可收起的章节导览；公众号稿保持全文和小标题。重点高亮与配图选择关键转折，不随篇幅机械增加，也不依靠大量一句话一段制造阅读节奏。
- 定稿后通读检查：段落是否自然、是否出现连续的一句话一段、观点是否反复、佛法表达是否准确且保持个人体会的边界。
- 公众号稿由 `scripts/export_wechat.py` 从文章 Markdown 生成。先把 `article.md` 的段落整理好，再导出；不要在 HTML 中用额外空行掩盖原文段落过碎的问题。
