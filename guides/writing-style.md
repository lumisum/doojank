# 无来写作规范：十段式与详解式

十段式原始规范见 [V1.0](wulai-ten-paragraph-v1.md)。2026-10-07新增与其并列的 [无来详解式](detailed-writing-style.md)。本文件负责写法选择、共同要求与十段式细则；详解式正文结构执行其专门规范，不继承十段式的段数、篇幅与章节限制。

## 总纲

**七层求全，三反求真。事实先于理论，现实高于模型。正文结构服从把问题讲清楚的需要。**

无来观世法提供后台分析，前台可选择十段式或详解式。佛法依然是底层观察向导，哲学、心理学、经济学、技术和系统科学用于具体问题的分析；正文使用现代现实语言。此前借鉴的Dan Koe方法不作为强制框架。

后续新文章优先采用[无来·以图立意法](image-led-writing.md)：立意→推演→取象→命题→入题→成文。先与作者讨论核心判断与逻辑，再生成能承载它的封面，查看成品后构建标题和画面开头。该方法控制创作顺序，十段式与详解式控制正文组织；按任务阶段交付，不因方法更新自动改写旧稿或发布。

十段式围绕一个核心判断，呈现十个短而完整的自然段。每段推进一层认识，保留支撑判断所需的因果与例子；不要把长稿按字数切成十块，也不要留下十条彼此独立的口号。详解式围绕一个核心问题连续展开，不分章节、不限定段数，中文正文默认3000–6000汉字。后台检查充分不等于能够穷尽所有现实，不宣称本法保证看透任何事情。

## 写法选择

作者明确指定优先。未指定时，集中而成熟、短篇能说明白的判断用十段式；需要较长因果链、概念区别、案例与边界才能说明白的问题用详解式。选择记录于制作笔记：`writing_mode: ten-paragraph` 或 `writing_mode: detailed`。下面的十段结构、字数与段长仅用于十段式；共同语言、事实核对、标题、导读与交稿规则适用于两种写法。X和公众号都可使用详解式，不按平台强制压缩。

## 后台：七层检查

| 角度 | 必须检查的问题 |
| --- | --- |
| 事实 | 发生了什么？哪些已核实，哪些只是当事人的说法？区分事实、推论、预测、价值判断，检查相关与因果、个例与整体。 |
| 认知 | 名称、定义、既有叙事和立场怎样影响理解？是否先接受结论再找依据？模型与对象有没有被混同？ |
| 人性 | 当事人想获得什么、害怕失去什么？利益、安全感、身份、控制和归属等哪些有依据？不凭空读心。 |
| 利益 | 谁收益、谁付出、谁承担风险、谁控制稀缺资源？激励怎样影响行动？技术、商业与价格判断分开。 |
| 结构 | 换一个人，问题是否仍容易发生？制度、家庭、组织、平台和市场如何持续产生结果？个人与结构可以共同起作用。 |
| 演化 | 机制继续运行数轮后，短期、中期、长期怎样变化？检查反馈、路径依赖、二阶效应与可能的自我抑制。推演写明条件。 |
| 价值与行动 | 哪些值得接受、改变、退出或坚持？读者现在能够怎样判断或行动？形成认知→判断→行动→验证→修正的闭环。 |

所有角度都要考虑，但某个变量不适用或缺乏材料时，在制作笔记简短注明，不能为了框架编造收益链或心理动机。分析结论用简洁证据、条件与编辑决策记录，不向正文展开后台分析过程。

## 后台：三重反转

1. **立场反转**：换到相关另一方，看原判断遗漏了哪些条件。区分对方提出的有效反例与立场差异，不用“各有道理”结束分析。
2. **因果反转**：检查 A→B、B→A、共同原因 C、双向反馈，以及没有 A 时 B 是否仍会发生。不能只为反常识把箭头倒过来。
3. **结果反转**：推演原机制走向极端，是否会反噬目标、产生二阶结果或改变稀缺价值。证据不足时保留条件，不强造终局。

反转先用于攻击作者自己的结论，再选择有支撑的认识进入文章。十段式要有一个反常识判断、一次因果反转和最后的结果反转；如果找不到成立的反转，返回补充分析或调整选题，不把修辞反差当成新事实。

## 前台：十个自然段

| 段落 | 承担的作用 |
| --- | --- |
| 1 | 以图立意时由成品画面的关键关系快速引出问题或核心判断，与真实困境衔接；不用“最近思考”“随着发展”等铺垫，不另加引图段破坏十段结构。 |
| 2 | 检查常见的第一理解，指出它遗漏的关键问题，不凭空替所有读者设立错误观点。 |
| 3 | 写人的欲望、恐惧或身份，用具体生活语言解释动机。 |
| 4 | 写收益、成本、风险与激励，说明机制为什么持续。 |
| 5 | 从个人进入结构，说明哪些条件反复产生同类结果。 |
| 6 | 拉长时间，写有条件的二阶或三阶结果。 |
| 7 | 第一次抬升，说明这件事改变了什么，形成阶段判断。 |
| 8 | 换立场或重看定义，补上前面被遮住的部分。 |
| 9 | 检查因果方向或反馈，给出经过分析的认知反转。 |
| 10 | 以结果反转收束，留下价值或行动方向；最后一句可以独立理解。 |

正文不标 1/10、第一层、第几重反转，不介绍写作框架。标题、摘要、小标题、图片及图注文案不计入十个正文段；图片插在段落之间，不把一段拆成两段。首尾句可单独引用，但保留在各自自然段内，不另加“金句段”导致超过十段。

每段一个主要判断，随后用必要理由或例子支撑。不能为套结构把数学证明写成人性阴谋，也不能把工程故障只归因于利益；先有题材事实，再决定该角度中什么值得表达。

## 语言与语气

### 当前写作要求：犀利、自信、逆向思维

中文与英文都要直接提出经过检验的核心判断，保持相同的力度、解释深度与事实边界。删去习惯性的“我觉得”“也许”“某种提醒”等缓冲；真正不确定的事实与因果仍准确说明条件，不用绝对化代替自信。英文以自然英语重构冲突与推理，不在翻译中软化判断，也不擅自升级为更大的断言。

文章优先按“读者的痛点→问题机制→解决之道”推进。以图立意时，开头先借最终封面可见的关系提出问题或判断，迅速连接这条路径，不把画面描述写成冗长铺垫。痛点要准确、直接，能概括该题真实而普遍的困境。一个零散生活片段不足以替代核心问题；抽象也不能变成空泛感慨。先点明读者正在付出什么、遭遇什么落差、为何难受，再用必要案例解释。不夸大痛点，不把作者讨论的预期落差擅自扩写为整个人或整段生活的失败。作者已经给出准确的问题描述时，优先保留它。

多用有解释力的逆向思维：检验“如果常见原因成立，结果是否应当不同”，观察目标实现后问题是否仍在，检查手段是否反过来消耗目标需要的条件。逆向追问先检验自己的判断，成立后用于正文推进；不机械倒转因果，不为刺激编造对立。详解式保持连续自然段，不强制三个章节或固定数量的反转。

少用“人生”“幸福”“自我价值”“命运”等宏大字眼来抬升普通问题。优先具体写目标、预期、差距、行动、条件、注意力和结果；题材确实需要时才使用宏大概念。刺激来自准确的矛盾、代价和认知反转，不来自训斥读者、制造羞耻或堆金句。

标题、开头痛点、正文主线与封面一起审视。图像呈现同一个核心关系，标题补出冲突或问题，正文兑现并给出解决路径。新奇与点击欲不能使四者各讲一件事。详见[标题与导读](#标题与导读)。

- 短、直接、低修饰、高判断密度。判断先于解释，本质先于案例；优先具体因果和关系，少用“重大、深刻、震撼”等评价。
- 有依据时直接判断；未知处明确“不足以判断”、条件或证据范围，不机械删除“可能”而把推测变事实。
- 结构性对比可用于真实关系，不能每段机械写“不是 A 而是 B”，不能把同时成立的因素写成虚假二选一。
- 允许锋利，判断针对问题。不能训诫读者、虚构经历、贬低人群或营造“只有我看懂”的优越感。
- 使用自然口语和完整自然段，不一句一行、不写鸡汤。保留作者个人判断与真实经验，不复制其他作者的特征性措辞。
- 佛法思想用于后台；除明确要求或题材不可回避外，不主动提读经、佛学术语和经典，不用经文固定开头或收尾。
- 反转不等于唱衰。指出限制后给出判断或行动方向，避免只有揭露和焦虑；也不强加乐观口号或保证结果。

## 十段式篇幅与共同平台要求

### 中文与公众号

默认十段，每段通常 60–150 字，全文以 **800–1500 字**为目标；特殊复杂议题可至约 1800 字。篇幅与段长是编辑参考，不能靠填充满足最低字数，也不能删掉理解必需的条件来硬压长度。

公众号仍是十段骨架，可加 **3–5 个有判断的小标题**，只作导航。标题不写“事实层”“第二重反转”，除非文章专门讲解方法。章节标题单独阅读，也应看出主旨推进。

此前 **2000–5000 字**不是十段式的默认要求。详解式作为独立写法，中文正文默认3000–6000汉字，在范围内写到核心问题、必要解释和重要疑问讲清为止，不靠重复填充。作者明确要求篇幅或保留完整长稿时优先执行，不自动把完整稿压成十段短稿。

### 英文与 X

英文十个自然段，每段默认 **20–50 words**，总体通常 200–500 words；保留同一核心判断、关键因果、例子与证据边界，用自然、专业、直接的英语重新组织，不逐字搬运中文，也不另造观点。正文不插图、不编号、不介绍七层与三反。首段和末段分别承担独立传播作用。

正式英文 Pages 与 `x.html` 共用审定的英文稿。用户需要单帖或 Thread 时另准备平台发布稿；超出当前账号单帖可用长度时可拆 Thread，十段本身不加教科书式编号。实际平台限额在需要发布时再核对，不承诺单帖总能容纳全文。

## 标题与导读

### 标题与封面联动（强制）

标题与封面共同表达文章的核心判断，不能各自独立定稿。新文章按[以图立意法](image-led-writing.md)先确定思想与逻辑，再生成封面；查看实际成品后，比较能承接画面并补出冲突、疑问或后果的标题。标题表层说画面，深层指向根本主题，易懂优先于强求双关。作者已有指定标题时通过适配封面完成联动。图像给读者一个醒目的视觉入口，标题让人立即知道这个入口与自己有什么关系。新奇、另类、易懂、有点击欲，并且正文能够兑现标题的承诺。

标题不只是重复画面里的物体名称，也不写成泛泛的道理。封面有明确隐喻时，优先让标题承接该隐喻；不为联动强行套用同一种比喻。待定时给三个高候选，分别说明如何与画面联动，并推荐一个。作者已经指定标题时保留，以适配封面的方式完成联动。英文标题保留同一核心冲突与视觉关系，用自然英语表达。

例如庞大动力装置由小指南针支撑的封面，配“AI 已经点火，你的人生往哪开？”：画面表达能力与方向的关系，标题把方向问题带回读者的人生。这个例子用于说明联动，不是所有文章都套用驾驶隐喻。制作笔记记录最终标题、封面隐喻和两者对应关系。

标题制造贴题且有依据的认知冲突，优先变化、稀缺、因果与结果反转。不要为了点击夸大、先给出正文无法支持的结论，或堆叠“我们都错了”。标题待定时给三个高候选及推荐理由；作者指定则保留。明确要求章回标题时仍按 5:5、7:7 或 8:8 核对。

中文导读不超过 **100 字**，英文 caption 不超过 **256 个字符**（包括空格、标点），写入各自 `summary`；复制 caption 的工具沿用现有导出器。导读不计正文十段，不替代第一段的判断。

## 资料与事实

正文以作者判断及推导推进，资料默认后台核对并记入 `production.md`，不复述机构报告，不添加超链接。技术等快速变化议题优先最近一年的一手材料，核对发布日期和结论范围；历史与经典按真实年代处理。

特定数据或他人的独有发现不可替代时，应少量交代必要出处，不能抹去来源伪装原创。事实、推论、预测与价值判断始终分开；比喻不是证据，反常识也不是可信度证明。

## 编辑检查与交稿

以下十项为十段式检查；详解式按 [连续解释与衔接标准](detailed-writing-style.md) 检查，重点是概念、理由、条件、反例与结论之间没有断链，不检查固定段数。两种写法共用后面的文件与交稿约定。

检查十项：开头判断、表象与事实、动机依据、利益结构、系统条件、时间推演、价值与行动、另一方视角、因果检查、结尾反转。缺少多项时回到分析；某角度确实不适用，要解释其与题材的关系，不硬凑。

确认十个正文自然段、单一主线、逐段递进、首尾可独立理解、限定准确、无重复与无关背景。删冗余时保留因果桥梁，不能删成十句互不相连的断言。

文章存 `articles/<日期-短名>/article.md`，策划与资料存 `production.md`。中文审定后再构建英文。语言与图片规格执行 [英文指南](english-edition.md) 和 [配图指南](image-style.md)；公众号 15px 和导出遵循 [排版规范](wechat-formatting.md)，X 文件遵循 [交稿指南](x-formatting.md)。

新方法不自动授权改写旧文章、制作图片、发布、推送或发送平台内容。当前任务明确要求成文或发布时，再完成对应工作。
