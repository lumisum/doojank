# 无来原创内容方法论 1.0

2026-10-11启用。适用于无来公众号与DooJank等平台。依据作者提供的[方法论原文](original-content-methodology-source.txt)整理；本次明确的口述润色边界优先于原文中的代写建议。历史十段式、详解式、七层三反及封面优先方法保存在[历史目录](archive/2026-10-11-writing-methods/)，不再是执行规则。

**问题为始，思考为引，实践为证，价值为终。**

目标是低频、高质量、可积累、可复用的原创知识。价值贯穿选题、研究与交付；实践与证据用于检验判断，时间用于观察长期有效性，不能仅凭经过时间便认定结论成立。

## 明确主线：How to

每篇文章都要明确：谁遇到什么问题，本文解决什么，读者获得什么价值，以及读后可以怎样行动或作出更好的判断。解释机制、数据和个人经历服务于这条主线，不停留在现象评论或观点展示。

How to不要求每篇写成操作手册；可以交付可用的判断方法、选择标准、排查路径、实践步骤或验证办法。探索稿仍要说明现阶段能怎样判断或继续验证，不能虚构已经找到解决方案。

这条要求是作者的内容目标，不扩大助手润色权限。原口述缺少明确问题、价值或行动落点时，在正文外简短提醒作者补充，不自行补写、不重排，也不阻止交付轻润色稿。持续提供可用价值是长期积累的重要基础，不保证平台流量或收益。

## 作者与助手的分工

作者负责独立观察、思考、实践、判断和口述表达。助手日常只做轻量文字润色：调整不顺的措辞、口述重复、明显口误与标点。保留观点、例子、论证、顺序、语气、限定词和结论，不代写，不补齐理论，不重构正文。

仅在作者明确要求选题讨论、资料核查、研究设计、翻译、排版或制图时，分别开展对应工作。研究建议在正文外提供；未解决的问题不由助手编造答案。发现有实质影响的事实或逻辑疑点，另列简短提示，由作者决定如何处理。

六步研究表达链用于作者研究与审阅参考，不用于把口述改写成六段文章；标题、封面和开头联动也不能授权助手改第一段。

## 原创、有用、可信

- 原创：来自作者的独立观察、研究、分析与表达，不要求从未有人说过。
- 有用：帮助明确的读者理解、判断或行动，不要求每篇都是教程。
- 可信：证据、推理、实践与适用边界支持结论。区分事实、当事人陈述、推论、预测和猜想。

公开研究可支持原创分析，但须准确归属。哲学提供视角，不替代工程测量、科学证据或实际观察；保留作者思想根基，不主动添加宗教词汇，也不删除原稿已有的哲学内容。

## 问题池与选题

建立问题池，优先来自真实困难、别人反复遇到的困难、主流判断中的矛盾、现有方法的局限和尚未充分解释的现象。选题检查：谁关心、为什么重要、已有答案遗漏什么、作者能怎样推进。

附件提出的长期方向“AI时代，人如何更好地思考、工作和生活？”及AI与工作、认知、选择等领域作为可用组织方向，作者可调整，不强制所有口述归入AI赛道。专题可用于研究归档，不自动改变网站目录或首页布局。

作者要求正式选题评估时使用[选题卡](../templates/original-topic-card.md)。允许字段待定，尤其核心结论可以空白。问题有价值但当前研究条件不足，可以留待以后；不为了预期文章先锁定答案。内部评分仅在作者要求时使用，附件未完整定义五项评分，不补造为强制标准。

## 低成本验证

优先提取已经发生的实践，再考虑最小研究。证据来源依次可用：日常观察、已有项目与公开案例复盘、小规模可重复实验、长周期多样本研究。记录时间、条件、过程、结果、失败、反例与局限，不凭一个案例推出普遍规律。未符合预期的实验也有价值。

研究设计与实际执行分开。提出计划不代表做过实验；不因方法论自动运行实验、产生费用、联系他人或开启定时任务。

## 作者的研究表达参考

提出问题 → 分析已有答案 → 提出假设 → 展示实践与证据 → 提炼有边界的结论 → 回到读者可获得的价值或行动。

它是内容是否回答问题的审阅参考，不要求六个自然段、六个标题或固定篇幅。助手只能在明确请求审阅时指出哪一环尚不清楚，不能自行补写或移动作者段落。

完整知识链：问题提出 → 假设形成 → 证据检验 → 判断修正 → 知识沉淀。没有确定结论时，可以诚实呈现进展与局限；不要为流量制造问题或确定答案。

## 三道审阅关卡

仅用于作者要求研究或发布审阅时，不阻挡单纯的口述润色。

1. 问题：真实、明确，有读者与价值吗？
2. 研究：有什么观察与证据，是否考虑反例，结论是否越界？
3. 交付：是否回答了问题，读者能得到什么，标题准确吗，长期是否值得保留？

缺口另列给作者，不自动写入正文、替作者定论或改稿。发布探索性作品不要求完整验证，只需准确交代现有材料的范围。

## 长期积累

创作与分发分开；不为频率凑作品。研究之间可以相互支持、修正和推翻，维护问题、证据与版本关系。作者需要时可观察30、90、180天后的搜索、收藏、引用、有质量的讨论与实际使用，不只看首日曝光。这些是可选复盘节点，不创建自动化，不保证流量或收益。
