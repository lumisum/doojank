# X 文章交稿

X 使用全英文文章，封面为 `5:2`，默认不写标题，以新奇图像表达主旨；正文纯文字，不嵌入封面或正文图。英文 Pages 与 X 共用定稿全文、标题和英文封面。

## 中文定稿与英文交稿

英文忠实翻译审定中文口述，执行[口述规范](writing-style.md)，不增删内容、不套固定结构、段数或字数，不为了X平台重写结论。需要单帖、Thread或短版时先明确范围，另作版本，不覆盖完整定稿。

`x.html` 是X Articles富文本复制页，不是官方HTML导入格式。是否适合当前平台长度在发布任务中核对；交稿不自动发到X。

## 文件与复制

- `x.html`：在浏览器中打开，点击 **Copy title** 复制标题到 X Articles 的标题字段；点击 **Copy formatted body** 复制正文到编辑器。封面 `images/cover-en.png` 单独上传，不随正文复制。
- 点击 **Copy caption** 单独复制英文导读到 caption 字段。导读取自英文版 `summary`，不混入正文复制范围；本地打开时也提供浏览器原生复制的回退方式。
- 英文 caption 严格不超过 256 个字符，空格、标点与换行均计入；导出器拒绝超限内容，不自动截断句子。
- `x.md`：可编辑、可归档的英文 Markdown 备用稿，与英文 Pages 全文一致。
- HTML 使用语义化小标题、自然段、加粗、斜体、删除线、链接、缩进和列表；X 专用渲染器独立于公众号颜色渲染器。预览页采用深空蓝主题、清楚的导读区、开篇段落层级与段间留白，但复制内容仅包含正文结构，不包含工具按钮、导读、说明、署名、图片或网页样式。内联代码退回普通文本，不伪装成平台支持的代码样式。
- X 官方说明其编辑器支持小标题、加粗、斜体、删除线、缩进与列表，未承诺直接导入 HTML/Markdown 文件或保留任意网页样式。`x.html` 是本地富文本复制页，不是官方导入格式。粘贴后检查小标题、加粗和段落；字号、颜色及间距由 X 编辑器决定，不能承诺像公众号一样复制全部样式。
- 如果本地文件的复制按钮受到浏览器限制，页面会选中正文，使用浏览器的复制快捷键。不要复制 HTML 源代码，也不要使用“粘贴为纯文本”快捷键来粘贴富文本。

官方参考：[About Articles — X Help Center](https://help.x.com/en/using-x/articles)，2026-10-05 核对其列出的编辑器排版功能；该说明不等于 HTML 标签或 CSS 样式的导入白名单。

## 生成

中文定稿后维护对应 `en/articles/<目录名>/index.md`，运行 `python3 scripts/export_x.py <目录名>`，在中文文章目录生成 `x.html` 与 `x.md`。生成器拒绝含内部图片的英文稿，避免把公众号图文误带入 X。交稿文件在 `_config.yml` 中排除，不作为单独的 Pages 网页；站点继续展示正式英文页面。

改编稿尚需审阅、需要保留原 Pages 正文时，可将含 `lang: en`、标题、导读与封面元数据的英文稿保存为该篇 `x-source.md`，使用 `python3 scripts/export_x.py <目录名> --source articles/<目录名>/x-source.md` 生成同样的复制页。此模式不更新正式英文页面；中文审阅稿可保存为 `x-review.zh.md`。`x-*.md` 从 Pages 构建排除。正式采用改编稿后，再同步英文页面并恢复默认生成流程。

## 复制页主题

`x.html` 使用DooJank的暖纸背景、深墨正文、雾灰辅助文字和夕照金强调，参照 [网站身份](site-identity.md)。署名为DooJank。复制正文仍输出语义化HTML，不带预览页的背景，最终显示样式由X编辑器控制。
