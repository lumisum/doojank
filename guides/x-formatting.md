# X 文章交稿

X 使用全英文文章，封面为 `5:2`，完整英文标题直接生成于图片像素；正文纯文字，不嵌入封面或正文图。英文 Pages 与 X 共用定稿全文、标题和英文封面。

## 文件与复制

- `x.html`：在浏览器中打开，点击 **Copy title** 复制标题到 X Articles 的标题字段；点击 **Copy formatted body** 复制正文到编辑器。封面 `images/cover-en.png` 单独上传，不随正文复制。
- 点击 **Copy caption** 单独复制英文导读到 caption 字段。导读取自英文版 `summary`，不混入正文复制范围；本地打开时也提供浏览器原生复制的回退方式。
- 英文 caption 严格不超过 256 个字符，空格、标点与换行均计入；导出器拒绝超限内容，不自动截断句子。
- `x.md`：可编辑、可归档的英文 Markdown 备用稿，与英文 Pages 全文一致。
- HTML 使用语义化小标题、自然段、加粗、斜体、链接和列表。预览页沿用青松绿，但复制内容只包含正文结构，不包含工具按钮、说明、装饰、图片或网页样式。
- X 官方说明其编辑器支持小标题、加粗、斜体、删除线、缩进与列表，未承诺直接导入 HTML/Markdown 文件或保留任意网页样式。`x.html` 是本地富文本复制页，不是官方导入格式。粘贴后检查小标题、加粗和段落；字号、颜色及间距由 X 编辑器决定，不能承诺像公众号一样复制全部样式。
- 如果本地文件的复制按钮受到浏览器限制，页面会选中正文，使用浏览器的复制快捷键。不要复制 HTML 源代码，也不要使用“粘贴为纯文本”快捷键来粘贴富文本。

官方参考：[About Articles — X Help Center](https://help.x.com/en/using-x/articles)，2026-10-04 查阅。

## 生成

中文定稿后维护对应 `en/articles/<目录名>/index.md`，运行 `python3 scripts/export_x.py <目录名>`，在中文文章目录生成 `x.html` 与 `x.md`。生成器拒绝含内部图片的英文稿，避免把公众号图文误带入 X。交稿文件在 `_config.yml` 中排除，不作为单独的 Pages 网页；站点继续展示正式英文页面。
