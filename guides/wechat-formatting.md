# 踱江客公众号文章排版规范

这套规范用于把文章整理成便于导入微信公众号的图文稿。每篇文章单独放在 `articles/<日期-短名>/` 目录中，原文使用 `article.md`，配图放在 `images/`，公众号导入文件为 `wechat.md` 和 `wechat.html`。运行 `python3 scripts/export_wechat.py` 会更新所有已发布文章的导入稿，并按时间更新 `articles/README.md`。

## 发布语言

微信公众号使用中文正文、中文标题与 2.35:1 无字封面，后续新稿默认正文不配图。正文配图或图中文字仅在用户明确要求时制作。X 的全英文文章及英文封面独立构建，英文正文纯文字，不混入公众号中文导出稿；参照 [平台语言规则](english-edition.md)。

## 视觉设计

HTML 排版使用DooJank的暖纸、深墨、雾灰与夕照金，参照 [网站身份](site-identity.md)。正文15px、行高1.95、段后20px；小标题18px，金色细线；重点使用深金色 `#996B34` 与加粗，正文深墨 `#35464E`、标题 `#24343B`、旁注 `#687478`。本地预览背景 `#F7F4ED`、正文纸面 `#FFFCF5`，轻层次 `#EFEADF`。文章图片保留原作品配色。

文稿从本篇2.35:1封面开始，随后是标题、导读、正文与署名「踱江客 · 个人手记」。复制正文去除所有背景，保留字号、段距、深色强调与图片；不把工具栏、脚本或外部CSS复制给公众号。X复制页同用暖纸色，输出语义化富文本，最终样式由X编辑器控制。排版仍使用平台支持的简单内联结构，不宣称所有样式都能原样保留。

公众号正文按 [`guides/writing-style.md`](writing-style.md) 的自然段落组织。一个 Markdown 段落会导出为一个公众号段落；不要将每句话拆成单独段落，也不要用额外段距制造“一句一行”的效果。导出前先检查 `article.md` 的空行和段落节奏。

新稿默认使用无来十段式：十个正文自然段，总长通常 800–1500 字，可加 3–5 个有判断的小标题作导航；复杂议题约 1800 字。标题、导读、小标题和图片不计入十段。配图放在段落之间，正文段落保持完整。明确要求保留长稿时按该任务处理，既有文章不因排版规范更新自动改写。

核心句和关键词应服务于文章论述，不做满篇加粗。长文通常选 2–4 处重点；同一篇文章不重复用同一种强调句式。

## 微信兼容约束

公众号草稿接口的正文 `content` 字段使用 HTML 内容，详见[微信公众平台新增草稿接口](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_add.html)。官方接口文档没有承诺所有粘贴样式都会原样保留；公众号编辑器还会处理粘贴内容。第三方公众号排版工具也基于实测建议将 CSS 写成内联样式，并避免依赖 `<style>` 块和 `class`（例如 [MDInline 项目说明](https://github.com/din4e/MDInline)）。因此本项目只使用简单段落、强调、链接和图片标签，将字号、颜色、行距、间距写在元素的 `style` 属性中，不依赖外链 CSS、脚本、复杂布局或浏览器专用效果。

Markdown 本身没有字号和颜色语法，所以 `wechat.md` 使用带内联样式的 HTML 片段，适合导入保留原生 HTML 的 Markdown 排版器；`wechat.html` 是同一份图文稿的可预览、可复制版本，封面已置于文稿开头。公众号标题和摘要仍可在编辑器对应字段填写。

生成文件使用网站公开图片地址，复制或导入后应检查图片是否正常显示；如图片未能保留或需要长期稳定展示，请在公众号后台重新上传对应图片，再发布。

原文中的 `images/01.png` 等相对图片路径以文章目录为基准，导出时转换为对应的 HTTPS 公开地址，不能在前面再次添加 `images/`。封面、分隔图和正文图均使用 HTTPS 地址，导出稿不引用本机 `file://` 图片。

## 使用方式

`wechat.html` 顶部的 **复制导读 / Caption** 按钮可单独复制中文摘要。此工具区用于交稿，不属于公众号正文；图文稿仍以封面开头。

1. **直接复制：**进入对应文章目录，打开 `wechat.html`，复制页面正文并粘贴到公众号图文正文区。
2. **Markdown 导入：**将 `wechat.md` 导入支持原生 HTML 的 Markdown 排版器，复制渲染后的富文本；不要把 Markdown 源码当纯文本粘贴到公众号。
3. 在公众号编辑器中填写标题和摘要，检查开头封面、正文高亮及配图，再保存或发布。

## 发布前检查

- 正文字号保持 15px，手机预览时检查阅读舒适度。
- 核心句高亮与文章原意一致，没有把个人体会包装成普遍教义。
- 封面在 HTML 图文稿开头，比例为 2.35:1；正文图片顺序与文章一致。
- 在微信公众号后台粘贴后检查字号、颜色、段距和图片；编辑器处理结果以后台预览为准。
- `wechat.md` 和 `wechat.html` 是发布辅助文件，不作为网站文章页面发布。
